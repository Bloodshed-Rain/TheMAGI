# MAGI 1.15.0

Your Melee game. Your corner.

This release brings the public downloads up to date with the current MAGI workspace. It includes the 1.13.0, 1.14.0 and 1.15.0 changes developed after the previous public release, 1.12.0.

## What's new

- **Input display in Play Mode.** Add **Input display** (labeled Stream) from the Customize module tray to see your controller as a GameCube wireframe. Each control lights while it is held: A green, B red, Z purple, the C-stick yellow, everything else white. The sticks move, and L and R brighten with how far they are pressed. It shows the inputs the running game read on each frame, so it is live during a game and dark in menus, and online it follows Slippi's delay setting. Only your controller is shown; when MAGI cannot tell which player is you, the display stays dark and says so.
- **Customize rebuilt around a module tray.** Every module is listed with what it shows and whether it needs a live session. Add it to either sidebar or drag its card, reorder by dragging a title, resize a sidebar by dragging its inner edge, and fold any module to its title. Save named scenes (Minimal, Live Coaching and Practice are built in) that restore module placement, widths, displayed stats and folded modules.
- **A motion layer.** Numbers count up to the exact value shown, themes open from the button you pressed, and charts, bars and the stock timeline animate in reading order. Everything is skipped when your operating system asks for reduced motion. Character wireframes idle with a slow ring of color.
- **Faster.** The page you land on appears without a loading placeholder, and the other pages load while you are idle. Character and pattern statistics are faster on large libraries.
- **Stable rankings.** Lists ranked by a count or a rate now order tied entries the same way every time. No count, rate or average changes.
- **Fixes.** Cards lift on hover again, and data tables use their full width, so the Library table's Stocks, Neutral, L-Cancel and Dmg/Op headers are no longer cut off.

## Downloads and requirements

- **Windows x64:** use `MAGI-Setup-1.15.0.exe` to install or update MAGI, or `MAGI-1.15.0.exe` for the portable app.
- **macOS and Linux:** use the attached macOS or Linux package when one is listed for this release.

Use the attached assets for the platforms available on this release. Native Play Mode hosting, the input display and embedded replay playback are Windows-only; macOS and Linux use external Slippi Dolphin playback. MAGI includes neither Slippi Dolphin nor a Melee game image. Configure your controller in Dolphin before playing. Hosted AI and cloud voice have their own availability, charges, and usage limits.

## Getting started and upgrading

1. Close your previous MAGI instance before opening the new build. Installing or downloading source alone does not replace an already running app.
2. Install or open the new package. Check that Settings shows **MAGI 1.15.0**.
3. Existing installations keep their local settings and data. The database upgrades itself on first launch; a backup of your local `.magi-melee` folder beforehand is useful for recovery.
4. The input display reads Dolphin's local spectator stream. If the module reports that the stream is off, set `SlippiEnableSpectator = True` in that Dolphin's `Dolphin.ini` and relaunch the game.
5. Add an AI provider in Settings → AI only when you want generated coaching. Parsing, statistics, browsing, notes, and game hosting work without AI.
